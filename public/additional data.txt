What's the story behind Zherani Shared Money Manager?
Zherani was created from a simple observation: most expense trackers only tell you what you've already spent. We wanted to build an app that helps people stay aware of their budget before recording new expenses.

Managing money with a partner, family, roommates, or even by yourself can quickly become complicated when expenses, accounts, and budgets are scattered across different places. We built Zherani to make shared money management simple, organized, and accessible.

By combining shared workspaces, budget tracking, multiple accounts, and customizable categories in an intuitive interface, Zherani helps people gain better visibility and control over their finances without unnecessary complexity.

Which are the primary technologies used for building Zherani Shared Money Manager?
Zherani is built with a modern, performance-focused technology stack to deliver a fast, reliable, and cross-platform experience.

Golang — Powers the backend API with high performance and efficient concurrency.
SvelteKit — Builds the responsive frontend and Progressive Web App (PWA).
PostgreSQL — Stores financial data securely with a robust relational database.
Redis — Improves performance through caching and session management.
Tauri — Enables lightweight desktop applications for Windows, macOS, and Linux using the same web-based codebase.
This stack allows Zherani to remain fast, scalable, and easy to maintain while providing a smooth experience across web and desktop platforms.
